# Web de Osmar Rotela – Electricidad y Mantenimiento

- `web/` → lo que se publica en https://osmar-rotela-electricista.netlify.app
- `src/consejos/` → un archivo por consejo (texto + animación)
- `src/build.py` → monta las páginas de consejos, la lista y el sitemap
- `fotos/` → fotos ya preparadas para la web
